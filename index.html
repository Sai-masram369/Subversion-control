How SVN Works:

  • Centralized Hub: Notice how both developers talk directly to one single master server. There are no direct connections between Developer A and Developer B.
  • svn update: Pulls down the latest filesystem changes from the central server into your local working directory. Watch the data travel down to the client.
  • svn commit: Pushes your local edits up to the central server. Doing this successfully increments the Global Revision Number for the entire repository tree.
